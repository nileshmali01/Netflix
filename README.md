#Netflix Clone using React and Firebase

Built a fully functional Netflix clone with React, Firebase, and styled-components, featuring a custom implementation of hooks, context, and portals. Integrated Firebase for authentication and Firestore for real-time data management. Utilized the TMDB API to dynamically fetch popular movies, trending shows, and top-rated content.

Key technologies: React (Custom Hooks, Context, Portals), Firebase (Firestore/Auth), Compound & Styled Components.

Note: Requires configuration of Firebase and TMDB API keys to run.
